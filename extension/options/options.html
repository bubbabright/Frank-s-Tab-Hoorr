Auto tab grouping Firefox only

Groups tabs as you browse. Rules pin a site to a named group; auto mode groups any site with 2+ tabs, named after its domain. Rules win over auto mode.

Close duplicate tabs

Used by the "Close Dupes" button in the popup. Controls which tabs count as duplicates and which one gets kept.

Idle cleanup

Closes idle normal tabs. Idle pinned tabs are discarded (unloaded, not closed). Active and audio-playing tabs are always safe.

History sampling
